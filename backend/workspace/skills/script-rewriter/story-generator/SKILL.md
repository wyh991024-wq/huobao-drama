# 创意扩写为完整故事

## 何时使用

原始内容只有一句创意、人物设定或几行梗概，缺少完整的起因、冲突和结局时使用。原始内容已经是完整小说或剧本时不要使用。

没有人可以回答问题，不要输出选项或提问，直接按下面的方法写出完整故事，再按剧本格式改写并保存。故事只作为改写的中间产物，最终保存的是格式化剧本。

## 写作方法

1. **先定六件事**：主角想要什么（看得见的目标）、挡在面前的障碍、背后的隐藏压力、要付出的代价、给观众的情绪承诺（爽、甜、虐、燃、怕、治愈中的一种为主）、结尾的余味。
2. **开场即冲击**：头三句话里就出现变化、危险、尴尬或欲望。不要从背景和世界观讲起。
3. **主角要主动选择**：主角不能只是被动反应，要做出有风险的决定。
4. **至少三次升级**：每一场戏要么揭示一个新事实，要么拿走一个安全选项，代价逐步变大。
5. **反转要有铺垫**：前面出现过的道具、台词或细节，在后面换一个意义回来。
6. **结尾回扣开头**：用一个具体的画面或物件收尾，不要用总结或说教点题。

## 写给短剧

- 篇幅按单集短剧控制：约 30-60 秒成片，对应 6-12 个镜头。
- 一切写成看得见的画面和听得见的台词，心理活动转成表情和动作。
- 角色少而鲜明，每个角色一个最突出的特征，要在行为里体现。
- 台词短，每句尽量不超过 18 个字，便于后续拆成 3-5 秒的镜头。
- 项目已有角色、场景、道具时，优先使用它们，保持外观和设定一致。

## 边界

- 原创写作，不照搬受版权保护的作品的情节、人名、台词和名场面。
- 提到某位作家或作品时，只借鉴通用技法（悬念、留白、反转），不模仿在世作者的独特文风。
- 不写涉及未成年人的性内容、真实暴力的操作细节，不把真实人物写成反派或丑闻主角。
