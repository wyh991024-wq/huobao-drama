# 剧本自审（保存前必做）

改写完成后、调用 `save_script` 之前，按下面的标准检查剧本，发现问题直接在剧本里改好再保存。不要输出审稿报告。

**例外：** 原始内容已经写好 `【景别/运镜·N秒】` 镜头行时，作者已经定稿，只检查格式，不改剧情、台词和节奏。

## 核心原则

1. **无聊是最大的问题。** 没有情绪起伏的段落要删减或加入有效冲突。
2. **第一集决定生死。** 观众要能一句话说清这是什么故事、主角是谁、冲突是什么。
3. **台词优先于内心独白。** 冲突和情绪要通过台词与动作表现出来，少用旁白和 OS。
4. **设定要写出来。** 人设标签和核心道具必须在剧本里有对应的行为、台词或画面，不能只停留在设定里。
5. **关键信息前置。** 人物关系、核心规则、主角目标要尽早交代，不让观众猜。
6. **观众不想动脑子。** 谁在做什么、为什么这样做，要一眼看懂。

## 逐项检查

- **开场**：前几行就出现变化、危险、尴尬或欲望，而不是交代背景。
- **情绪点**：每集至少命中一个——笑点、泪点、燃点、悬念或治愈感。
- **结尾**：每集结尾有让人想看下一集的钩子，或者有明确的情绪落点。
- **正反馈**：主角吃了亏，要在本集内给出一次明确的回报或安慰，不能只有负面情绪。
- **台词**：每句台词都有目的（推进、施压、隐藏意图、制造笑点）；换个角色名还能说的台词，说明缺少角色特征，要改。
- **衔接**：相邻台词逻辑连贯，角色态度转变要有动作或台词过渡。
- **角色数量**：同一场戏出场角色不宜太多，避免观众分不清主角。
- **可拍性**：每个动作都是画面上看得见的；心理活动改写成表情、动作或台词。

## 去 AI 味

剧本的动作描写和台词避免以下句式，出现就改写成具体的动作、画面或台词：

- `不是X，而是Y`、`问题不在于X，在于Y`、`真正的X不是Y`
- `总之`、`综上所述`、`关键在于`、`值得注意的是`、`让我们`
- `这不仅是……更是……`、`这就是……的意义`
- 结尾的总结式金句、口号式抒情

例：`她不是害怕，而是不甘心。` → `她攥紧了合同，指节发白，没让眼泪掉下来。`
